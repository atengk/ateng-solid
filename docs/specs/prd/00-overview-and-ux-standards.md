## 1. 产品范围与双态运行模型

### 1.1 纳入范围矩阵
1. **基础与异常页面（5 个静态路由）**：登录页 `/login`、轻量工作台 `/dashboard`、个人中心 `/profile`、无权限页 `/403`、未命中兜底页 `/404`。
2. **核心管理模块（12 个动态路由）**：租户管理（`/system/tenant`）、租户套餐（`/system/tenant-package`）、用户管理（`/system/user`）、角色管理（`/system/role`）、菜单管理（`/system/menu`）、部门管理（`/system/dept`）、岗位管理（`/system/post`）、数据字典（`/system/dict`）、系统参数（`/system/config`）、操作日志（`/system/oper-log`）、登录日志（`/system/login-log`）、在线会话（`/system/online`）。
3. **非独立页面消费能力**：静态枚举（`/admin/system/enums`）不设独立菜单页面，由各业务下拉框与标签组件统一消费；用户头像直传与 Fesod Excel 批注导入导出集成于对应业务页内。

### 1.2 单/多租户双态切换规则
系统由后端配置 `ateng.solid.tenant.enabled`（**默认 `false`**）控制，前端通过登录前置接口返回的 `tenantEnabled` 开关驱动界面切换：

| 维度 | `tenantEnabled = false`（默认单租户态） | `tenantEnabled = true`（SaaS 多租户开启态） |
| :--- | :--- | :--- |
| **登录页** | 隐藏租户编码输入框，固定走默认租户 `"0"`（`000000`） | 展示租户编码输入框（默认占位/预填 `000000`） |
| **顶栏租户控件** | 完全隐藏 | **普通租户用户**：只读胶囊展示归属租户名<br>**平台超管（`tenantId="0"` 且含 `super_admin`）**：可检索下拉切换工作租户 |
| **跨租户提示条** | 不存在 | 仅平台超管切至非 `"0"` 租户时显示，支持一键切回平台默认租户 `"0"` |
| **平台专属菜单** | 隐藏`租户管理`、`租户套餐`；`菜单管理`、`数据字典`正常可见 | **平台租户 `"0"` 超管**：全部平台菜单可见<br>**普通租户或超管切入他租户视角**：自动隐藏平台专属菜单 |

## 2. `AdminLayout` 主布局壳交互规范（方案 A）

### 2.1 三区骨架与响应式断点
- **左侧导航栏（`228px` / 折叠 `60px`）**：
  - 顶部固定 `48px` 品牌标识区（Logo + `ateng-solid` 标题，折叠时仅显示 Logo）；
  - 菜单按领域分组展示（首页、组织权限、基础配置、多租户[按开关]、审计安全），字符串图标经后端 `icon` 字段映射至 `@element-plus/icons-vue`；折叠态鼠标悬停菜单项弹出子菜单或名称 Tooltip；
  - 视口宽度 `< 768px` 时侧栏自动收起，点击顶栏折叠图标以抽屉浮层展开并带半透遮罩。
- **顶部栏（`48px`）**：
  - 左侧：侧栏折叠/展开按钮 + 动态面包屑（`域名称 / 当前页面名称`，不可点击断链时不加链接样式）；
  - 右侧（按从左到右顺序）：租户切换器/只读胶囊（按 `tenantEnabled` 显隐）➔ Light/Dark 主题切换按钮 ➔ 用户头像与昵称下拉（`个人中心`、`修改密码`、`退出登录`）。
- **工作区最大化模式**：
  - 点击页签栏最右侧最大化图标时，隐藏左侧导航栏、顶部栏与跨租户横幅（保留内容区与恢复按钮），支持按 `ESC` 或点击恢复图标退出。

### 2.2 多页签栏（`TabsNav`）与 `<KeepAlive>` 规则
- **默认状态**：页签栏（高 `36px`）默认开启展示，允许用户在客户端轻量偏好中隐藏页签栏；
- **固定工作台**：`/dashboard` 固定处于第一位且 `affix: true`（无关闭按钮、禁止拖拽移位、批量关闭命令自动跳过）；
- **横向溢出与右键菜单**：页签超出容器宽度时支持平滑横向滚动；每个页签右键触发 6 项标准菜单：
  1. `刷新当前页`（禁用缓存再重新挂载当前组件实例，重拉接口数据，不整页刷新浏览器）
  2. `关闭当前`（`affix` 页签置灰禁用）
  3. `关闭其他`（无其他可关页签时禁用）
  4. `关闭左侧`（左侧无非固定页签时禁用）
  5. `关闭右侧`（右侧无可关页签时禁用）
  6. `关闭全部`（仅保留全部 `affix` 页签并激活首个固定页签）
- **激活回退规则**：关闭**当前正在查看**的页签后，优先激活其**右侧相邻页签**；若右侧无页签，则激活其**左侧相邻页签**。
- **工程实现提醒**：`@atengk/element-plus` `AtengTabsNav`（后 `#376`）接入时固定传入 `:emit-close-on-batch="false"` 与 `@batch-close` 聚合事件，并通过 `:menu-icons` 替换为线性 SVG 图标；全部单关/批关统一收口至 `useTabsNav`（`cachedViews`）单一数据源，消除状态多次跳变。

### 2.3 超管切换工作租户（`X-Tenant-Id`）强隔离联动
当 `tenantEnabled = true` 且平台租户 `"0"` 的 `super_admin` 在顶栏选择目标租户 `T` 时：
1. 调用 `TenantManager.setTenantId(T)` 更新请求头 `X-Tenant-Id`；
2. **强制关闭除 `affix`（`/dashboard`）外的所有已打开页签**，清空跨租户表单与列表状态缓存；
3. 重新拉取目标视角下的权限与菜单路由（若原所在页面在目标视角下不再可见，自动跳转 `/dashboard`；否则停留在当前路由并重拉数据）；
4. 当 `T !== "0"` 时，在页签栏下方持续显示克制的非阻塞态提示横幅：`"当前正以平台超管身份查看工作租户：【租户名】(租户ID)，平台专属菜单已自动隔离隐藏"`，右侧提供 `[切回平台默认租户 (0)]` 快捷按钮。

## 3. 通用检索、表格、分页与弹层标尺

### 3.1 `AtengQueryForm` 检索区规范
- **独立检索卡架构（上下双卡分体）**：检索表单自成独立白色卡片（`--solid-radius-lg` `8px` 圆角 + `1px` 细线边框 `--solid-border`），与下方表格分页卡保留 `12px` 间距，禁止两者白底混叠或与外层边界错位；
- **列数断点**：默认按容器宽度自适应（`<768px: 1列`、`768~1200px: 2列`、`1200~1920px: 3列`、`>=1920px: 4列`）；针对常规全宽精简检索页显式收口 `:cols` 以消除桌面端操作区被迫换行；
- **复杂度分级折叠策略（`ADR-0005`）**：
  - **精简检索（≤3 项且容器够宽）**：全宽页（`menu`/`role`/`post`/`config`/`dept`/`online`/`tenant-package`）与 `dict` 右栏（2 项）统一设 `defaultCollapsed = false`、`showCollapse = false`，其中 3 项全宽页配置 `:cols="{ xs: 1, sm: 2, md: 4, lg: 4, xl: 4 }"`、2 项页配置 `:cols="{ xs: 1, sm: 3, md: 3, lg: 4, xl: 4 }"`，确保主流桌面端单行容纳全部条件与 `[查询][重置]` 且不出现冗余 `收起` 按钮；
  - **窄分栏与多条件检索（≥4 项）**：`/system/dict` 左栏（44% 窄分栏 3 项）及 ≥4 项列表（`user`、`tenant`、`login-log`、`oper-log`）保持 `defaultCollapsed = true`、`collapsedRows = 1`，超出首行可容纳字段数时自动折叠并展示 `展开 ▾ / 收起 ▴` 按钮；
- **回车与防重**：在输入框按 `Enter` 触发查询时必须前置判断 `!event.isComposing` 防止中文输入法选词误触发；查询与重置按钮接入 `v-idempotent` 防连点；嵌套于 `AtengTable #query` 时仅在 `AtengTable` 绑定 `:pagination` 避免重置双重请求。

### 3.2 `AtengTable` 表格卡与分页规范
- **表格分页卡边界统一**：工具栏、表格主体与底部分页栏整体收纳于独立表面卡片内，采用统一 `8px` 圆角、`1px` 细线边框与 `16px` 四周内边距，彻底消除操作列与分页末字 `0px` 贴边问题，并与分栏侧边卡片（如部门架构树面板）保持视觉一致；
- **弹性封顶与滚动模式（`ateng-ui#380` 与 `ADR-0005`）**：
  - 桌面横排态下，全站 12 个业务列表页（8 个单分页表 + 2 个无分页树表 + `user`/`dict` 双栏面板，分栏外层配 `h-full min-h-0`）统一消费 `:auto-height="16"` 与 `auto-height-mode="max"`（`<el-table :max-height>` 语义）：数据少时紧包内容随数据走、不留大片空白；数据超出一屏剩余空间时自动封顶并锁定工具栏、表头与底部分页栏，仅表格数据区内部纵向滑动；
  - 当视口处于 `<768px` 移动端或 `user`/`dict` 垂直堆叠态时，自动关闭封顶高度（`autoHeight = false`），退回自然流整页滚动，避免小屏上下多层滚动嵌套；
- **分页主轴与等宽基线**：默认每页 **`10` 条**，可选 `[10, 20, 50, 100]`，标准布局 `total, sizes, prev, pager, next, jumper`；采用 **总条数置左（`共 N 条`）+ 翻页控制与跳转置右** 的两端分布（与 `AtengPageSkeleton` 骨架对齐），页码、总条数、跳转输入框与数值列强制 `.tabular-nums`；
- **空态与单页自适应收敛（`ateng-ui#379`）**：
  - `total === 0` 时默认自动隐藏底部分页栏（由 `AtengEmpty` 承担空态与清空筛选引导）；
  - `total > 0` 且总页数 `<= 1` 时自动收起冗余 `jumper`（`前往 _ 页`），保留 `共 N 条` 与 `[10条/页] < 1 >`；`>= 2` 页时完整展示跳转框；
  - 容器较窄（含双栏分栏与 `< 768px` 移动端）由 `AtengTable` 自动折行/紧凑适配并保证零横向溢出；全站分页列表统一消费默认自适应分页契约（同步移除 `/system/dict` 等局部手写 `pagination-layout` 覆盖）；
  - 非 `AtengTable` 分页（`AtengExcelFeedback` 错误清单分页与 `AtengPageSkeleton`）同步对齐换行与 `.tabular-nums`（决策归档见 `ateng-solid-admin-web/docs/adr/0004-dual-card-table-and-adaptive-pagination.md`）。
- **工具栏标准布局**：
  - 左侧主操作区：`+ 新增<资源>`（主按钮）、`批量删除`（无勾选时置灰禁用，显示已选条数）、按需挂接 `导入` / `导出`；
  - 右侧 5 工具：`刷新`、`密度切换（宽松 12px / 默认 8px / 紧凑 4px）`、`斑马纹开关`、`列配置（支持显隐勾选与拖拽排序并按 storageKey 本地持久化）`、`表格全屏（ESC 退出）`。
- **操作列约定**：固定右侧（`fixed="right"`），统一使用文本动作按钮（`编辑`、`更多`、`删除` 等），禁止仅用无文字且无 `aria-label` 的孤立图标。
- **三态缺省区分**：
  - 接口报错：`网络加载失败` + `[重试]` 按钮；
  - 存在有效筛选条件且无匹配：`未找到符合条件的<资源>` + `[清空筛选条件]` 按钮；
  - 无筛选且数据为空：`暂无<资源>数据` + 按权限展示 `[新增<资源>]` 引导按钮。

## 4. 数据展示、安全护栏与全局错误反馈

### 4.1 脱敏展示与内存真明文
- **只读表格与详情页**：手机号按 `3-4-4` 脱敏（`138****5678`）、邮箱保留首字符与域名（`a***@domain.com`）、身份证保留前 6 后 4，**点击单条复制按钮始终复制完整真明文**；
- **编辑表单**：点击“编辑”加载详情接口返回的完整未脱敏字段（`内存真明文`），严禁将带星号掩码的字符串回填进输入框导致保存覆盖真实数据。

### 4.2 高危操作与保护护栏
1. **状态切换二次确认**：表格行内 Switch 开关点击后弹出明确后果提示的确认框，用户确认后再发 `PUT /{id}/status`，取消则保持原状。
2. **删除确认**：单行删除与批量删除均须二次确认并点名实体标识（如账号名、角色名、租户名）。
3. **内置与自身保护**：以下对象在表格操作列与多选框中**直接置灰禁用停用/删除动作并悬停说明原因**（同时后端接口执行硬拦截）：
   - 平台默认租户（`tenantId = "0"` / `tenantCode = "000000"`）；
   - 平台内置超级管理员角色（`roleKey = "super_admin"`）与超级管理员用户；
   - 当前登录账号自身（`userId === currentLoginUserId`）的停用、删除与强退在线会话操作；
   - 系统内置参数（`configType = built-in`）的删除操作。

### 4.3 全局响应码与可操作错误文案规范

| 状态/错误码 | 触发场景 | 前端标准交互反馈 |
| :--- | :--- | :--- |
| **`200`** | 操作成功 | 写操作弹出简短正面反馈（如“已保存用户”“已停用角色”），动作动词与按钮名称保持一致 |
| **`400` / `100xxx`~`102xxx`** | 参数/业务规则拒绝 | 表单校验类精确回显至对应字段下方或保留抽屉弹窗并顶部提示具体原因与恢复动作；严禁只弹笼统“失败” |
| **`401` / `101005`**（已认证态） | 未登录、令牌过期、被强退或运行时所属租户停用/过期 | 防重入清空本地凭据、`TenantManager` 重置回 `"0"`、清理 `DictManager`、卸载动态路由与页签缓存，提示原因并跳转 `/login?redirect=<原路径>` |
| **`100002`** | 平台超管跨租户切换/访问失效目标租户 | **严禁注销 `"0"` 平台会话**；自动复位 `TenantManager("0")`、清空 `DictManager`、重刷 `/auth/info` 与 `/auth/routes`，提示原因并回退 `/dashboard` |
| **`101004`** | 登录页触发防爆破锁定 | 跳过全局弹窗，登录页读取 `(err.cause as Result<LoginLockDetailVO>)?.data` 驱动 `IP` / `ACCOUNT` 差异化倒计时 |
| **`403`** | 零菜单受限态或接口越权/账号禁用 | 零菜单已登录账号访问业务路径跳转 `/403` 引导页（提供“返回工作台”与“退出登录”防死锁出口）；持有部分菜单的用户直达未授权路径因仅注册已授权动态路由而统一落入 `/404` 隐藏路由存在性；接口级越权弹出明确拒绝原因（不跳转整页） |
| **`409`** | 并发乐观锁冲突或唯一键冲突 | 保持当前表单不清空，提示“数据已被其他用户修改或编码已存在，请刷新核对后重试” |
| **`429` / `40003`** | 限流拦截或 `v-idempotent` 防重 | 弹出克制警告提示 `"操作过于频繁，请稍后再试"` |
| **`500` / `502` / `503` / `504` / 断网** | 系统未捕获异常、网关故障或网络超时 | 按状态分层提示中文友好文案（`500` 为 `"系统繁忙，请稍后再试"`、`502`/`504` 为 `"网关或后端服务连接异常，请稍后重试"`、`503` 为 `"服务暂不可用，请稍后重试"`、断网/超时为 `"网络请求超时或服务连接异常，请稍后重试"`），实施 `2s` 同类气泡合并与传输层英文/HTML 清洗，附 `traceId` 及一键 `[复制 TraceId]` 按钮，**绝不向用户暴露 SQL、表名或 Java 堆栈** |
